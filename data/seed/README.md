# Seed data

`categories.json` and `products.json` here are copied into `data/*.json` on first read by `src/server/db/json-store.ts`. The live copies at `data/*.json` are gitignored — they can be freely mutated at runtime by admin CRUD (Phase 6).

Placeholder images point to `picsum.photos`. Replace with real product photos via the admin panel (Phase 6) or by editing the seed and deleting the live JSON to re-seed.
